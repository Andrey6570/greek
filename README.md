# Ελληνικά · 5 минут

Приложение для ежедневной практики греческого (A1 → B2) по урокам «Μαθήματα 1-190». Работает офлайн как PWA.

- `index.html` — приложение (карточки с повторением, задания, правила с закреплением, колода)
- `data/base.js`, `data/deck_extra.js` — данные колоды (`deck_extra.js` генерируется)
- `src/parts/*.json` — исходные части колоды по урокам
- `tools/build.py` — сборка и проверка: `python3 -I tools/build.py`
- `sw.js`, `manifest.webmanifest`, `icons/` — офлайн-режим и установка на телефон

Запуск локально: `python3 -m http.server` в корне и открыть http://localhost:8000.
Установка на Android: открыть адрес в Chrome → меню → «Установить приложение».
Личные данные из уроков в колоду не включены. Переводы и варианты в заданиях подготовлены автоматически и не проверялись носителем.

## APK
Сборка идёт в GitHub Actions (`.github/workflows/android.yml`): колода собирается, приложение кладётся в assets оболочки `android/` (WebView), готовый APK появляется в Releases. Запускается автоматически при пуше в `main` или вручную (Actions → Android APK → Run workflow). APK работает без интернета.
