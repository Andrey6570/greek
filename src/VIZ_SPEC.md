# Задача: обогатить правила объяснениями, схемами и визуализацией
Ученик — русскоговорящий, учит греческий (A1→B2). В указанных JSON-файлах (/home/user/greek/src/parts/) у каждого правила в "rules" уже есть: id, title, l (номер урока), body (краткие строки), quiz, drill. НЕ меняй id, title, l, quiz, drill. Для КАЖДОГО правила нужно ДОБАВИТЬ два поля:

## 1. "more": массив из 3–6 строк — подробное объяснение по-русски
Простым языком: зачем это нужно, как образуется, когда употребляется, чем отличается от похожего, типичные ошибки русскоговорящих. Допускается <b>…</b>. Греческие примеры давай с переводом в скобках. Не повторяй body дословно — расширяй.

## 2. "viz": массив блоков визуализации (2–5 блоков на правило), в нужном порядке. Типы блоков (строго такие поля):
- {"t":"formula","parts":[{"x":"θα"},{"x":"+","c":"op"},{"x":"глагол (аорист)"}],"note":"Пояснение под схемой"} — формула-схема из цветных плашек. c: "a","b","c","d" (разные цвета для разных частей) или "op" для знаков + → =. Если c не указан — цвет по порядку.
- {"t":"table","title":"Название","head":["Лицо","Форма"],"rows":[["εγώ","γράφ<b>ω</b>"],…]} — таблица (склонение, спряжение, сравнение форм). Окончания/изменяемую часть выделяй <b>…</b>. До 8 строк, до 4 столбцов.
- {"t":"compare","a":{"h":"Заголовок A","items":["…","…"]},"b":{"h":"Заголовок B","items":["…","…"]}} — сопоставление двух похожих вещей (когда что).
- {"t":"steps","title":"Как образовать","items":["Шаг 1 …","Шаг 2 …","Шаг 3 …"]} — алгоритм по шагам (3–5).
- {"t":"timeline","items":[{"h":"Раньше","x":"έγραφα","ru":"писал (бывало)"},{"h":"Один раз","x":"έγραψα","ru":"написал"},{"h":"Сейчас","x":"γράφω","ru":"пишу"}]} — шкала времени/вида (2–4 точки), для времён и видов глагола.
- {"t":"ex","items":[{"gr":"Греческий пример с <b>ключевым</b> словом","ru":"перевод"},…]} — 3–5 живых примеров.
- {"t":"tip","k":"tip","x":"Лайфхак/мнемоника"} или {"t":"tip","k":"warn","x":"Типичная ошибка: …"} — подсказка или предупреждение.
В каждом правиле обязательно: минимум один блок table ИЛИ formula ИЛИ compare ИЛИ steps ИЛИ timeline (выбери подходящий смыслу), блок ex и хотя бы один tip. Не делай блоки для галочки — они должны реально объяснять.

## Как править
Через Python (python3 -I): json.load → добавить поля к каждому rule → json.dump(ensure_ascii=False, indent=1). Не создавай других файлов в src/parts. После правки проверь скриптом: у каждого rule есть "more" (3–6 строк) и "viz" (2–5 блоков), каждый блок имеет допустимое t и обязательные поля; в table все строки одной длины с head.
