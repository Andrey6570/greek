# App Store (iPhone): чек-лист

**Нужно от вас:**
1. Apple Developer Program (99 $/год) на ваш Apple ID.
2. В App Store Connect: создать приложение (Bundle ID `com.andrey6570.greek`, название, язык, SKU).
3. Создать ключ App Store Connect API (Users and Access → Integrations → Keys), роль App Manager. Понадобятся Key ID, Issuer ID и файл `.p8`.
4. Узнать Team ID (Membership details).

**Секреты репозитория (Settings → Secrets → Actions):**

| Секрет | Значение |
|---|---|
| `APPLE_TEAM_ID` | Team ID |
| `ASC_KEY_ID` | Key ID ключа API |
| `ASC_ISSUER_ID` | Issuer ID |
| `ASC_KEY_P8` | содержимое файла `.p8` целиком |

С этими секретами workflow `iOS build` сам соберёт подписанный архив и загрузит его в TestFlight (автоматическая подпись через API-ключ). Без секретов он собирает только неподписанную сборку для симулятора, чтобы проверять, что проект собирается.

**Что уже готово:** иконка 1024×1024 без прозрачности (`store/graphics/icon-1024.png`), скриншоты 1290×2796 (6,9"), тексты (`listing-ru.md`, `listing-en.md`), политика конфиденциальности.

**Шаги в App Store Connect:**
1. Карточка: название, подзаголовок, описание, ключевые слова, категория «Образование», URL политики конфиденциальности, контакты.
2. Конфиденциальность приложения: «Данные не собираются».
3. Возрастной рейтинг: анкета (4+).
4. Экспортное шифрование: уже указано `ITSAppUsesNonExemptEncryption = false` (шифрования нет).
5. Выбрать собранную в TestFlight сборку, отправить на проверку.

**Риски проверки Apple:**
- Правило 4.2 (минимальная функциональность): приложение-оболочка вокруг сайта может быть отклонено, но здесь это полноценное офлайн-приложение с карточками, заданиями, словарём и сохранением прогресса, обычно такие проходят.
- Права на материалы: учебные тексты должны быть вашими или использоваться с разрешения автора.

## Установка на свой iPhone без App Store (бесплатно)
В Releases лежит релиз `ios-latest` с файлом `greek-ios-unsigned.ipa` (неподписанный).
1. На компьютере установите **AltStore** (altstore.io) или **Sideloadly** (sideloadly.io).
2. Подключите iPhone, войдите своим Apple ID в программе и выберите `greek-ios-unsigned.ipa`.
3. На iPhone: Настройки → Основные → VPN и управление устройством → доверять своему Apple ID.
4. Бесплатная подпись действует 7 дней: AltStore обновляет её автоматически, пока компьютер в той же сети. Прогресс при обновлении сохраняется.
Для постоянной установки без перепродписи или раздачи другим людям нужен Apple Developer Program (TestFlight / App Store).
