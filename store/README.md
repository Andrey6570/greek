# Подготовка к сторам

Содержимое папки `store/`:
- `listing-ru.md`, `listing-en.md` — тексты карточки (название, описание, ключевые слова)
- `privacy-policy.html` — политика конфиденциальности (копия лежит в `docs/privacy.html` для GitHub Pages)
- `graphics/` — иконки (512 для Google Play, 1024 для App Store) и графика функции 1024×500
- `screenshots/android/` — скриншоты 1080×1920 (Google Play), `screenshots/ios/` — 1290×2796 (App Store, 6,9")
- `google-play.md`, `app-store.md` — пошаговые чек-листы публикации

Адрес политики конфиденциальности: `https://andrey6570.github.io/greek/privacy.html` (после включения GitHub Pages: Settings → Pages → Branch `main`, папка `/docs`).
